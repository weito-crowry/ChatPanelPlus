# C52 複数再生デバイス受入

## 範囲

- Issue #20: 通知音の再生デバイスを複数選択できるようにする。
- 実装対象はOptionsの共通出力先checkbox、旧単一保存値との互換、複数出力へのfanout、試聴・ChatGPT回答完了音・Codex監視終了音の再生結果である。
- C51の通知別enabled/soundId/volumePercentは独立したまま。C48〜C50の既存実機観測は本受入で変更しない。
- 本書のChrome実機項目は、ユーザーが登録済みrepo直下`D:\weito\Documents\src\codexapp\ChatPanelPlus\dist`をreloadし、ChatGPTをF5した後に手動実施する。自動テスト結果をChrome受入のPASSに置き換えない。
