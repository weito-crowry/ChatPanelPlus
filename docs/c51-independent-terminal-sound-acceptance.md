# C51 ChatGPT / Codex通知音の独立設定 — Chrome受入手順

Issue #21。ChatGPT回答完了音とCodex監視終了音を別々に設定し、音源ライブラリと出力先だけを共通利用できることを確認する。

## 実機手順

Chromeの登録済みロード元はリポジトリ直下`dist/`。実機受入はユーザーが手動で行う。

1. `chrome://extensions`で既存のChatPanelPlusをreloadし、対象ChatGPTページをF5する。
2. Optionsの「通知・音声」にChatGPT回答完了音とCodex監視終了音それぞれのON/OFF、音源、音量、選択音試聴があることを確認する。音源ライブラリと出力先の管理欄は各1つであることを確認する。
3. 2つの設定を異なる音源・音量にし、一方ずつ試聴する。各試聴がその通知の選択音・音量を使い、同じ出力先へ再生されることを確認する。
4. 保存後にOptionsを再読込し、両方のON/OFF・音源・音量が別々に維持されることを確認する。JSON exportに両方の値が含まれ、import後も維持されることを確認する。
5. ChatGPT回答完了音だけOFFにしてChatGPT回答完了を発生させ、音が鳴らないことを確認する。Codex監視終了音をONにしたままCodex監視終了を発生させ、Codex音だけが鳴ることを確認する。逆方向も同様に確認する。
6. 同じカスタム音源を両方で選び、片側だけ選択を変えた場合に他方の保存値・ドラフト選択が保たれることを確認する。両方が選択中なら音源削除で両欄が既定音へ切り替わることを確認する。保存済み両参照とドラフトだけの参照を分けて確認する。
7. 旧設定JSON（Codex専用項目なし）をimportし、ChatGPT側の旧有効状態・音源・音量がCodexにも引き継がれることを確認する。保存後に片側を変更し、再読込後も独立することを確認する。Codex項目の一部だけがあるJSONでは、明示項目を保ち、欠落項目だけ旧ChatGPT設定から補完されることを確認する。
8. 各音量0%、各通知OFF、共通音源欠落、出力先利用不可を確認する。OFF/0%/欠落音源は既存の意味を保ち、他方の通知に影響しないことを確認する。
9. 会話別ミュート中・owner不明ではCodex終了音が鳴らないことを確認する。終端eventの重複、初回取得時に既に終了済みのwatch、手動監視解除が通知音を発生させないことを確認する。
10. 同じCodex終端eventを二重に受けても再生が一度だけであることを確認する。通常のChatGPT回答完了音が従来どおり動くことも確認する。
