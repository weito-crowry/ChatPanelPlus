# GitHub Issues 順次処理計画

**Goal:** 未完了15件を既存実装と照合し、実装可能なものを修正・検証・独立レビューし、実機依存は統合チェックリストへ残す。

**Architecture:** 既存のTypeScript/React、schemaVersion 1、既存保存・入力経路を維持する。ユーザーの一括実行指示に従い既存checkoutで実装は直列、調査とレビューは並列。Issue本文・コメントが仕様。追加の承認ゲートは設けない。

**Tech Stack:** Windows / PowerShell / pnpm / TypeScript / React / Node test runner。

**Spec:** GitHub #14, #2, #8, #15, #16, #1, #13, #11, #7, #6, #17, #5, #12, #9, #10 と今回のユーザー指示。

## Global Constraints

- Chrome自動操作・一時プロファイル・新規worktree・権限追加を行わない。
- 既存15ファイルの変更は#14回収対象として保全し、無関係な変更を混ぜない。
- schemaVersion: 1、既定5タブ20ボタン、ユーザーデータを維持する。
- 原因不明の実機障害は推測で修正せず、観測手順と再開条件を記録する。
- 手書きコードは500物理行・32768 bytes以下。
- mergeしない。完了条件に実機があるものはOpenを維持する。

## Review Focus

- タブ削除・保存競合・旧JSONでカスタム資産を保持する。
- 編集操作から送信を発生させない。実機未再現を修正済みと扱わない。
- 履歴端で遅延DOM更新後の位置・高さを再評価する。
- コピー対象のUIが存在するか確認してから変更する。
- 調査専用Issueを機能実装へ拡張しない。
