## 合成サンプル

短いMarkdown比較用。コピー結果には見出し・記号・空行・コード・インデントが残るか確認する。表示対象がMarkdown描画仕様なら意味も確認する。


長文はローカルで次のPowerShellを使って生成できる（クリップボードは明示実行時に上書き）。標準はLF、CRLF版は最後に置換する。ユーザー本文は使用しない。

```powershell
$line = ('x' * 98) + "`n`n"
$sample = $line * 100 # 10,000 UTF-16文字、200改行
$sample | Set-Clipboard
# 100,000文字は $line * 1000。CRLF版は $sample.Replace("`n", "`r`n")。
```

HTML付き比較は、ブラウザで上記短文の見出し/箇条書き/コードを含む表示を手動コピーし、プレーンテキスト版と分けて記録する。サンプルの文字数・段落数・形式だけを結果へ残す。

## #6 旧ID・診断版の手動整理

1. 通常Chromeの `chrome://extensions` で各カードの名前・ID・有効状態・ロード元を記録する。アプリ側からChromeを操作しない。
2. 固定ロード元が `ChatPanelPlus-Content-Probe-20261021` のカードを日常利用候補とする。名前とversionだけで断定しない。ロード元が不明なら削除せず確認する。
3. 有効な日常版のOptionsで設定JSONをエクスポートし、ローカルへ保管する。各IDのchrome.storage.localは別領域。既定JSONエクスポートに会話統計台帳等が含まれるとは扱わない。音声ファイルなど外部資産は必要なら元ファイルも保持する。
4. 旧ID・診断版が無効なら調査目的で有効化しない。すでに有効な対象IDの設定を確認する場合は、会話ページを閉じた状態でそのOptionsを使う。無効版のOptionsを開けず必要な資産を確認できない場合は、無効のまま保持して整理を保留する。現行データの初期化・他IDへの一括上書きを行わない。
5. 不要版はユーザーが1つずつ手動で無効化し、ChatGPTを再読込して動作確認する。フォルダ移動・改名・拡張再登録は行わない。
6. 削除はID内ストレージの消失を伴うため、保存範囲を確認できなければ無効化のまま保持する。旧IDフォルダ・診断フォルダ・段階バックアップは削除/改変しない。
