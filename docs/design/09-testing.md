# テスト戦略・品質ゲート設計

- 文書ID: CPP-DESIGN-09
- 状態: 初版
- 依存: 00-architecture.md、01～08 の各機能設計
- 現行: 既存テスト16件が引継ぎ時に合格。今回の設計書作成では一切再実行していない。

## 1. 品質方針

- 静的検査とユニットテストに加え、ChatGPT の実DOM・入力欄・クリップボード操作について Chrome 実機検証を必須とする。
- v7.2 の挙動互換性と新しい設定編集機能を独立に受け入れる。
- テスト結果は「自動試験」「Chrome実機確認」「未確認」を区別して報告する。テストの存在を動作成功と同一視しない。
- 仕様が未確定の振る舞いは仮の期待結果を捏造せず、残件として明示する。

## 2. 既存品質ゲート

- pnpm check:size: 手書きコードは1ファイル500物理行以内・32KiB以内。
- pnpm lint: 静的解析（check:size を含む）。
- pnpm typecheck: TypeScript 型検査。
- pnpm test: テスト実行。ただし現状のスクリプト定義では先にビルドを実行する。
- pnpm build: 正式拡張機能の成果物生成。dist を更新する。
- pnpm deploy:chrome: Chrome登録済み新IDフォルダへの反映。一般的なテストコマンドと同列に自動実行しない。

既存の16件（引継ぎ時実測）はソース構造、ビルド・配布資産、設定スキーマ、サイズ検査が中心。新機能に対する実機保証はまだない。

## 3. ユニットテスト対象

- default UI: 20ボタン、5タブ、全ID・色・ラベル・原文（長文は完全一致）。
- editor adapter: エディタ候補選定、未接続、不可視、選択 Range の有効/無効、先頭挿入時の改行規則、既存本文保持。
- actions: ID と kind/action の対応、未知アクション拒否、自動送信経路なし、JST のタイムゾーン固定と形式。
- UI state: 左端可視タブ既定、タブ切替記憶、非表示・順序変更時のフォールバック、全タブ非表示、最小化。
- settings: 既定値投影、部分的上書き、JSON 検証、スキーマ移行、不正値、ID 重複、保存とリセット。
- options: ドラフト編集・保存/取消、並べ替え、表示状態変更、既定値復元、インポート・エクスポート往復。
- clipboard: 読取成功・権限拒否・空文字・手動入力/キャンセル、二重操作。
- lifecycle: 初回マウント、重複防止、DOM切断・復帰、不要な observer 登録の抑制。
- conversation statistics: Unicodeコードポイント計数、初期スナップショットと自動集計の分離、送信後の新規Turn Key、ストリーミング完了、F5/再集計の冪等性、編集/再生成/分岐、部分DOM、破損スキーマ、容量・保存失敗、設定キー分離。
- statistics DOM/UI: 現行Turn/Assistant/DIL属性と親子関係、重複DOM排除、状態不明時の未確定表示、パネルホバー/詳細/再集計、イベントからの意図しない送信がないこと。
- message passing: 既存 OPEN_OPTIONS が回帰しない。

## 4. 統合テスト対象

- React ボタン押下 → ディスパッチャー → Editor Adapter → 成功/失敗通知まで。
- Options 保存 → Storage 更新 → ChatGPT パネル反映まで。
- タブ再配置・非表示設定 → タブ選択・最小化・再読込まで。
- ユーザー設定をカスタマイズした後の全デフォルト復元。
- Clipboard 非同期処理中のタブ切替を確認し、Composer Element が取得開始時と挿入直前で異なる場合は挿入中止・通知となり、新しい Composer に書き込まれないことを確認する。
- Shadow DOM マウント/再マウント中のイベント登録と重複挿入防止。
- ビルド出力と Manifest/Service Worker/Options の参照整合。

## 5. Chrome 実機の最低確認行列

| 操作・条件 | 確認内容 |
| --- | --- |
| 新規会話を開く | パネルが重複なく現れ、ChatGPT が普通に使える |
| 既存会話を開く | 会話の読み込みを阻害せず、パネルを表示できる |
| 会話間の SPA 遷移 | パネル復旧、古い Composer への誤入力なし |
| 指示タブで「全文」 | 先頭へ正確に文字列挿入、送信なし |
| 複数行定型文「引継ぎ」 | 改行・空白・末尾 LF が原文どおり |
| 壁打ち開始 | 長文原文が省略・改変なく挿入される |
| 入力済み本文あり | 既存の空白・改行を破壊しない |
| 選択中/途中カーソルでコピペ | 指定位置だけに挿入、選択置換が正確 |
| Clipboard 拒否 | 手動ダイアログとキャンセルが機能 |
| クリア | 現在の Composer だけクリア |
| 5タブ・20ボタン | 構成と動作、色・表示名が正確 |
| タブ/ボタンの非表示・並べ替え | 設定内容が表示へ反映 |
| Options 保存・JSON 往復 | 保存・復元・初期化が正常 |
| 最小化・復帰 | 見た目と状態保存が正常 |
| ライト／ダーク・表示幅変化 | 表示が破綻せず、入力欄を隠さない |
| DOM の高頻度更新 | 二重マウントや著しいパフォーマンス劣化なし |
| 会話統計の新規ターン・回答完了 | INPUTを自動計上し、完了した選択回答だけOUTPUTへ反映。ChatGPTの通常送信を妨げない |
| F5・SPA会話切替 | 既存ターンの重複加算なし、Conversation IDごとの分離 |
| 古い会話のスクロール | 表示だけでは過去ターンを計上しない。再集計ボタンで表示範囲を追加 |
| 回答再生成・ユーザー発言編集 | 旧回答/旧分岐を合算しない |
| 統計詳細UI | Turns、ホバー、詳細小窓、再集計、最小化、Escape、保存失敗表示を確認 |

ブラウザ側のアクセス制限やクリップボード許可ダイアログは自動試験と混同しない。実機テストをユーザーが行う場合は手順と期待結果を簡潔に示す。

## 6. 障害と回帰の扱い

- 旧IDの 429 障害を今回の新IDに再現するための操作を本番Chromeで勝手に行わない。
- 既存会話が読み込めない、入力内容が消える、勝手に送信される、誤った Composer に書き込む事象は重大欠陥として受入停止。
- 見た目の軽微な差異はスクリーンショット基準の差分として報告し、機能欠落と区別する。
- 脆弱な DOM セレクタだけに依存する試験で全環境互換を主張しない。
- 会話統計で使う ChatGPT DOM 属性は非公開の恒久契約ではない。Phase 0で確認したスナップショットと自動テストは、現在のChatGPT実機での継続動作を保証しない。
- 検査が失敗した場合は原因を特定して必要箇所を修正し、既存ソースを無関係に改変しない。

## 7. 完了・引継ぎ時の必須報告

各実装単位で:
- 対象設計書・受入条件
- 変更したファイルと公開 API
- 実行したコマンド、実測 PASS/FAIL と件数
- 実機検証の有無、未検証項目
- 既存 v0.1.5 と v7.2 の互換性上の差分
- 次作業に必要な依存関係と課題
- Git 状態とコミット/デプロイ実施の有無

全機能統合後、ChatGPT による独立レビューを実施してから最終受入とする。
