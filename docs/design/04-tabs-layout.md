# タブ・レイアウト・最小化状態仕様

- 文書ID: CPP-DESIGN-04
- 状態: 初版
- 依存: 00-architecture.md、02-panel-ui.md、03-prompt-actions.md、05-settings-storage.md（後続）
- 原典: Tampermonkey v7.2 の UI.groups、readActiveTabId、setMinimized、buildUI

## 1. 基本構造

UI 定義は「常時表示グループ」と「タブグループ」の2層構造。見た目と実行アクションを安定 ID で結び、設定では表示順・可視性・見た目・テキストを変更できる。

標準の常時表示ボタンは now-btn、paste-btn、clear-btn、chat-btn の順。タブの ID と表示ラベルは以下の順。

| ID | 既定ラベル | 標準ボタンID（左から） |
| --- | --- | --- |
| directive | 指示 | full-btn, summary-btn, translate-btn, search-btn |
| control | 会話制御 | zokudake-btn, handover-btn |
| wall | 壁打ち | wall-start-btn, wall-task-btn, wall-sum-btn, wall-resume-btn |
| binary | 二択 | yes-btn, no-btn |
| quad | 四択 | a-btn, b-btn, c-btn, d-btn |

タブ内で複数行に折り返す場合も、データ順序は変更しない。

## 2. データモデル

- ButtonDefinition: id / groupId または tabId / label / color / kind / action / text / visible / order
- TabDefinition: id / label / visible / order / buttons
- ViewState: selectedTabId（nullable）、minimized
- UserSettings: 既定値からの上書きと UI 状態

定義上の ID と定型文は 03-prompt-actions.md を正とする。データ構造名とファイルは 05-settings-storage.md で確定し、表示用の label と内部 ID を混同しない。

## 3. 初期タブ選択・永続化

- 初回起動／タブ選択状態未保存の場合は、可視タブを order で並べた先頭（最も左）を選択。
- v7.2 既定配置では directive が左端だが、実装で directive を固定値として特別扱いしない。
- ユーザーが別タブをクリックすると selectedTabId を更新・保存する。次回のページ再読み込み・新規会話へ移動しても、設定に残る限り選択タブを復元する。
- 保存 ID が見つからない、非表示、または壊れている場合は、可視タブの左端を選び直して正規化する。
- タブ順を変更しただけなら、既存の有効な選択タブを保持する。これは「初期値は左端」と「ユーザー選択の記憶」を両立するための規則。
- 可視タブがゼロの場合は selectedTabId=null、タブ行・内容行を非表示とし、常時表示グループは機能する。タブを一つでも再表示したら先頭可視タブへ移る。
- 新規・非表示・不存在タブを押す操作は処理を行わない。

## 4. 表示・非表示と並び替え

- 各ボタンは表示/非表示を独立に持つ。非表示のボタンを押す UI は表示しないが、定義とカスタマイズ値は保持する。
- 各タブも表示/非表示を独立に持つ。非表示のタブに属するボタンの設定は保持する。
- ボタンの並び替えは、まず元の常時表示グループ内／各タブ内の順序変更を実装する。
- 他のタブへのボタン移動や常時表示グループとの相互移動は v7.2 にない拡張であり、今回の基本実装では未確定。勝手に暗黙対応しない。
- タブの並び替えは visible なものだけではなく、全タブに安定した総順序を保存し、隠れたタブの復元後も順序が破綻しないようにする。
- 同順位、重複 ID、知らない ID、配列破損は保存・読込時に検証し、安定した決定的順序へ正規化する。
- 全ボタンを非表示にしてもパネルや設定導線は失われず、設定画面から復旧できる。

## 5. 最小化・復帰

- 初期値は展開状態。
- 最小化すると、標準パネルの常時表示ボタン群・タブ行・内容行は視覚的に畳み、上辺の枠線と中央 SVG 復帰トグルを残す。
- SVG は縮小時に約 180 度反転し、aria-label と title を「復帰」へ変更。展開時は「最小化」へ戻す。
- 最小化状態は永続化する。新規チャット、ページ再読み込み後も状態を復元する。
- 最小化時にも ChatGPT 本体の入力欄と会話は通常どおり操作できる。最小化/復帰で入力欄本文・選択状態を書き換えない。
- 設定初期化時の最小化状態の取り扱いは 05-settings-storage.md の「全初期化」契約に従う。

## 6. React の状態管理

- React は現在の settings と viewState から表示ツリーを導出する。並び替え・表示切替のたびに DOM 要素を手動移動しない。
- 配列キーは安定 ID を使用し、並び替え後の再マウントが不要な入力操作を誘発しないようにする。
- タブクリック、最小化操作、Options変更イベントが競合した場合も、最新の妥当な設定が反映される。
- UI とストレージの更新間に失敗が起きたときは、一時表示と永続化状態の差分を隠さず、ユーザーにエラーを通知する。
- 新しい UI ツリー定義や将来の機能を追加しても、既存 ID を理由なく変更しない。

## 7. 受入条件

- 設定なしで v7.2 の上段4ボタン、タブ5個、タブ内16ボタンが正しい順番で表示される。
- 初期アクティブタブは左端可視タブ。タブ切替後は再読み込みでもそのタブを復元する。
- タブ順を移動して初期化した場合の左端選択規則が機能する。
- 選択済みタブを非表示にすると左端可視タブへフォールバックする。
- 全タブ非表示・全ボタン非表示でも画面例外が起きず、Options から戻せる。
- ボタン・タブの順番と表示を変更して保存し、再起動後も維持する。
- 最小化/復帰、状態保存、SVG 表示、アクセシビリティラベルが動作する。
- 既定状態に戻すと元の v7.2 配置と表示へ復帰し、未送信入力や会話履歴を変更しない。
