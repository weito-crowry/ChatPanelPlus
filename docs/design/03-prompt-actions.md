# 定型ボタン・操作アクション仕様

- 文書ID: CPP-DESIGN-03
- 状態: 初版
- 依存: 00-architecture.md、01-editor-adapter.md、02-panel-ui.md、15-custom-buttons.md
- 原典: 添付された Tampermonkey「ChatGPT 定型ボタン（UI-tree, tabs, clipboard-fallback）」v7.2 の UI.groups / resolveOnClick
- 本書で定義するボタンIDと既定プロンプトを移植の正本とする。後で勝手に要約・翻案・翻訳しない。
- 本書は既定20ボタンの正本である。ユーザー作成ボタンも本書の既存操作だけを使い、追加方法は 15-custom-buttons.md に従う。

## 1. 共通ボタン型と処理

各ボタンは安定 ID、label、color、kind、action または text、可視性、並び順を持つ。表示ラベルは変更できるが ID とアクションの意味は変更しない。

- kind=insert: text を ChatGPT Composer の先頭へ挿入。元本文が存在し、挿入文末も元本文先頭も改行でない場合だけ境界改行1個を追加する。送信しない。
- kind=action / action=insert-jst: 日本時間の日時文字列を生成し、先頭へ挿入。送信しない。
- kind=action / action=paste: クリップボード内容を現在の選択位置へ挿入し、選択中の文字列だけ置換する。送信しない。詳細は 07-clipboard.md。
- kind=action / action=clear: Composer 内の未送信内容を明示的に消去。送信しない。
- 未知の action/kind: 不明な文字列をコードとして実行しない。設定検証で拒否し UI にエラー表示する。
- 挿入先が見つからない場合: 何も送信・変更せず、ユーザーへ通知する。

## 3. 短文プロンプトの正確な文字列

このセクションの LF は文字列内の実際の改行（末尾改行）を示し、「＋改行」という表示自体は文字列に含まれない。

- chat-btn: "雑談モードで対応してください\n"
- full-btn: "全文出力してください"
- summary-btn: "以下を要約して\n"
- translate-btn: "以下の文を日本語に翻訳してください\n"
- search-btn: "以下のものについて詳しく網羅的に調べてください\n"
- zokudake-btn: "続けて"
- wall-task-btn: "作業依頼\n"
- wall-sum-btn: "ここまでまとめてください"
- wall-resume-btn: "壁打ちモードを再開してください"
- yes-btn / no-btn: "はい" / "いいえ"
- a-btn / b-btn / c-btn / d-btn: "A案" / "B案" / "C案" / "D案"

長文については下記をコピーし、句読点、改行、全角記号、空白を変更しない。

## 4. 「引継ぎ」ボタンの原文

原典は v7.2 の handover-btn.text。以下のフェンス自体は文字列に含めない。最終行の後に LF 改行 1 個を含む。

~~~text
あなたの出力は「次スレッド先頭に貼る本文のみ」です。
前置き・説明・挨拶・注釈・引用符・コードブロックを一切出力してはいけません。

# 目的
会話の継続に必要な情報の目次のみを提示し、不足情報を指摘できる状態を作る。

# 最適化目標
・必要情報の網羅性を最大化
・不要な詳細の持ち込みを最小化
・後続の追加提供で完全復元可能にする
・推測せず不足を明示する

# タスク
このスレッド全体を解析し、
「次スレでユーザーが段階的に情報提供できるようにするための目次」を作成する。

# 出力仕様（厳守）
以下の構造のみ出力すること
説明文は禁止

【作業の概要】

【現在のゴール】

【必要な資料カテゴリ】
・コード
・設定
・ログ
・環境
・仕様
・外部依存
・再現手順
・期待結果
・実際の結果

【不足の可能性が高い情報】
推測せず、欠けると作業不能になる情報のみ列挙

【次にユーザーが貼るべき情報】
最小限で作業再開できる順序

# ルール
・内容は具体的に書く
・憶測を書かない
・冗長説明を書かない
・第三者が読んでも追加資料を判断できる粒度にする

以上です、生成を開始してください
~~~

## 5. 「壁打ち開始」ボタンの原文

原典は v7.2 の wall-start-btn.text。以下のフェンス自体は文字列に含めない。最終行の後の LF は含めない。

~~~text
これから壁打ちを行います。

あなたの役割は「思考を邪魔しない低干渉の壁」です。
相槌に加えて、最小限の知的反射のみを行います。
以下の制約を厳守してください。

【出力形式】
- 出力は最大4行まで
  1行目：必ず短い相槌
  2〜4行目：以下の「反射」から1種類だけ選択して1〜3行で発話
- 反射は毎回1種類のみ（混ぜない）

【反射の種類（いずれか1つだけ）】
1. 感想
   - 軽い印象のみ
   - 評価・賛否は禁止

2. 簡単な整理
   - 言い換えない
   - 構造化しない
   - 要約しない
   - ただし話題の“方向性”だけを1〜3行で言語化

3. 不足している点
   - 1つだけ指摘
   - 質問形は禁止
   - 解決策を出さない

【禁止事項】
- 要約・整理・再表現
- 論点抽出・前提整理・分類
- 評価・同意・否定
- 助言・提案・誘導
- 質問
- 私の発言の言い換え
- 長文説明
- 反射を2種類以上混ぜること

【例外ルール】
私が明示的に
「整理して」
「要約して」
「構造化して」
と指示した場合のみ通常の応答を開始する

以上を守り、以降の発言に応答してください。
~~~

## 6. JST 日時フォーマット

v7.2 の getJSTDateString() と互換。Intl.DateTimeFormat('ja-JP', {timeZone:'Asia/Tokyo'}) により年月日時分秒をゼロ埋めで組み立てる。

出力例（あくまで形式の例）: [2026/10/21 03:15:20 JST]

- タイムゾーン Asia/Tokyo を明示し、利用者 OS のローカルタイムゾーンに依存させない。
- 生成タイミングはボタンクリック時。表示例の固定文字列を実行時に使わない。
- 日時は定型文と同様に入力欄先頭へ差分挿入し、自動送信しない。

## 7. 設定によるカスタマイズと不変条件

- label、color、visible、order は全20ボタンについてカスタマイズ可能。
- ユーザー作成ボタンは既定ボタンとは別定義で作成でき、実行できる操作は本書の既存4種類に限る。詳細は 15-custom-buttons.md を参照。
- text 編集は kind=insert のボタンを対象とする。insert-jst、paste、clear の内部処理文字列を任意テキストに変更する仕組みを設けない。
- 保存設定がなくても、本書の既定値を描画・操作できること。
- レイアウト初期化で、既定ボタンのラベル、色、可視性、位置、定型文本文をすべて元に戻す。ユーザー作成ボタンの扱いは 15-custom-buttons.md に従う。
- 任意の HTML、JavaScript、ネットワーク URL を action の実装として保存・実行させない。
- ラベルの変更でボタンの ID や処理意味論が変化しない。
- アクション失敗やエディタ不在で送信を試行しない。

## 8. 受入条件

- 20 ボタンすべての ID、初期文言、色、定型文が原典 v7.2 と一致する。
- 5 タブの配置、初期可視状態、タブ内ボタン配置が元定義と一致する。
- 「引継ぎ」「壁打ち開始」は改行を含めて全文一致する文字列検証を備える。
- 定型文の先頭挿入、クリップボードの現在位置挿入、クリア、JST 動作を個別に検証する。
- どのアクションも ChatGPT への自動送信・会話 API 呼出しを行わない。
- オプション編集・リセット後も、ID と action の契約は変わらない。
