# パネル UI・外観仕様

- 文書ID: CPP-DESIGN-02
- 状態: 初版
- 依存: 00-architecture.md、01-editor-adapter.md
- 視覚基準: ユーザー提供の ChatGPT 画面スクリーンショット（2026-10-21）および Tampermonkey v7.2 の CSS
- 本書は見た目・表示構造の仕様であり、ボタンの処理内容は 03-prompt-actions.md に委ねる。

## 1. 画面上の役割

- ChatGPT Composer の直前（上部）に、既存ユーザースクリプトと同様のメイン操作パネルを表示する。
- メインパネルと、現行 v0.1.5 にある右下の小さな「ChatPanelPlus 設定」導線は区別する。最終的な設定導線の重複整理は後続の Options 設計で決定する。
- ChatGPT の入力欄、送信関連ボタン、会話本文、ヘッダーを覆ったり自動で書き換えたりしない。
- アプリ初回表示から標準配置の操作ボタンが利用でき、ユーザーが設定変更しなくても実用できること。

## 2. 標準配置と順序

パネルタイトルの直下にコンパクトな会話統計トリガーを置く。通常時は `128 Turns` のようにTurnsだけを表示し、ホバーで集計済み総文字数を示す。クリック時の詳細小窓は既存Shadow DOM内に重ねて表示し、Composerを大きく押し下げない。

最上段の常時表示ボタン（左から）:
1. 現在時刻
2. コピペ
3. クリア
4. 雑談

次のタブ行（左から）:
1. 指示
2. 会話制御
3. 壁打ち
4. 二択
5. 四択

タブ内容行は選択したタブのボタン群を表示。初回・無効保存値からの復帰は **現在表示されているタブの左端** を選ぶ。標準配置では「指示」が左端のため、初回は「全文」「要約」「翻訳」「調べて」を表示する。ユーザー提供スクリーンショットは「会話制御」選択中の参考画面であり、初期選択状態ではない。

設定でボタンやタブを非表示・並び替えした場合、同じ構造に新しい順序を投影する。配置変更のために処理用 ID を変更しない。

## 3. 既定のビジュアル

Tampermonkey v7.2 の見た目を可能な限り再現するが、スタイル実装は Shadow Root に閉じた CSS へ整理してよい。元の明示値を主な初期目安とする。

| 要素 | 既定デザイン |
| --- | --- |
| パネル | ChatGPT と調和する白系背景、薄いグレーの 1.5px 境界線、16px 角丸、弱い影 |
| パネル余白 | 上下 12px・左右 24px を参考に、元 UI に近い密度 |
| 上段ボタン | 横並び、折返し可、間隔 12px 前後 |
| ボタン | 8px 18px 程度の内側余白、20px 角丸、白文字、太字、15px 前後、控えめな影 |
| タブ | 角丸上辺、薄い枠線、横並び、13px 程度の文字、アクティブなものを背景と枠線で区別 |
| タブ下線 | 選択状態と連続した薄い区切り線 |
| タブ内容 | 選択タブの操作ボタンを横並び（横幅不足なら折返し） |
| 最小化トグル | パネル上辺中央に重ねた薄色 SVG、クリック可能な十分広い領域 |
| 右下設定導線 | 当面現行 UI を保持し、移植後に統合方法を評価 |
| ダークモード | ChatGPT の対応色変数に追従しつつ、未定義時は安全なフォールバック |
| レスポンシブ | 狭い幅では折返し。入力欄や ChatGPT の操作に重ならない |

v7.2 のスタイル参照値: パネル gap:10px / margin-bottom:24px、タブ gap:6px、ボタン類は明示の hover と active の視覚応答、最小化 SVG は 140×52px 前後。ブラウザの拡大縮小やフォント差を考慮し、スクリーンショットとのピクセル単位の完全一致は要求しない。

## 4. ボタンと色

色は処理識別子から分離した既定 UI データとして保持し、Options から変更可能にする。標準配色の例:

- 現在時刻 #5a9edc、コピペ #2ca24c、クリア #888、雑談 #8b5cf6
- 全文 #6e5adb、要約 #4b5563、翻訳 #e0912d、調べて #1ca3ec
- 続けて #10a37f、引継ぎ #0b7285
- そのほか壁打ち、二択・四択は v7.2 の色定義をデフォルトに転記する。

色の変更は CSS の表示にのみ作用し、action や prompt text を変更しない。文字の可読性に関する確認を行うが、ユーザーが指定した色を勝手に別の色へ改変しない。

## 5. コンポーネント境界

- PanelShell: 外枠と全体配置
- UtilityRow: 常時表示ボタン
- TabBar: タブラベル、選択状態、切替操作
- TabContent: 表示対象ボタン群
- ActionButton: ラベル、色、説明、クリック処理の接続
- MinimizeToggle: 最小化・復元、アクセシビリティラベル
- Toast / ManualPasteDialog: フォーカス可能な通知 UI（07-clipboard.md）
- SettingsEntry: Options を開く導線
- ConversationStatistics: Turns表示、総文字数ツールチップ、詳細小窓と手動再集計（詳細は 12-conversation-statistics.md）

命名は例示であり、実コードの公開 API は実装前レビューで確定する。これらのコンポーネントに ChatGPT DOM セレクタや localStorage アクセスを直接埋め込まない。

## 6. 表示・操作状態

- パネルのマウント、タブ切替、設定変更、最小化/復帰は React 側の状態で管理する。
- 最小化時は v7.2 と同様に枠線と復帰トグルを残し、上段ボタン・タブ・タブ内容を非表示にする。
- 最小化時は会話統計と詳細小窓も非表示にする。統計詳細は閉じるボタンまたは Escape で閉じ、Escape はIME変換中に奪わない。
- 開閉時のトランジションは元 UI 程度の短いものに限定する。アニメーション中も ChatGPT の入力欄へのフォーカスを不要に奪わない。
- 設定変更後に表示されなくなったタブを選択状態として残さない。詳細は 04-tabs-layout.md。
- 何らかの理由で Composer が見つからないときは、誤位置に重複描画するより復旧待ちの安全な状態とする。既存 UI の破壊はしない。

## 7. Shadow DOM / CSS の方針

- パネルの CSS を Shadow Root 内へ局所適用し、ページ本体へ汎用クラス名のスタイルを注入しない。
- ChatGPT が提供するテーマ用 CSS 変数は参照できる範囲で利用し、未提供時は独自デフォルト値へフォールバックする。
- フォント、ボックス寸法、focus-visible、hover、disabled のスタイルを明示し、React 内の button には type="button" を設定する。
- ダイアログのレイヤー順位とスクロール抑制は ChatGPT の入力欄を隠さないよう実機で調整する。不要なグローバル z-index の競合を避ける。
- 内部スタイルを刷新しても初期デザインを大幅変更しない。

## 8. デザイン受入条件

- 初期表示が画像のレイアウトと形状・余白・色・ボタン順で概ね一致する。
- 最上段4ボタンとタブ5個が設定なしで表示される。
- Turnsを通常表示し、ホバーで集計済み総文字数、クリックでTurns/INPUT/OUTPUT/総文字数と再集計を表示する。
- 詳細小窓がComposerを大きく移動させず、最小化中に表示されず、統計操作から送信を発生させない。
- 初期選択タブは左端の「指示」。その下に「全文・要約・翻訳・調べて」が表示される。
- 「会話制御」を選択すると「続けて・引継ぎ」が画像と同じ関係で並ぶ。
- 最小化→再展開でき、復元後にボタン、タブ状態、未送信入力が失われない。
- 設定により色・ラベル・可視性・順序を変更してもレイアウトが破綻しない。
- ライト／ダーク、横幅の広い画面／狭い画面、Chrome の表示倍率変更を実機で検証する。
- パネルは ChatGPT の通常操作を妨げず、Chrome 既存会話の読み込みも阻害しない。
